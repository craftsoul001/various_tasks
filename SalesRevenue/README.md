# Sales Revenue
***
Простейшее веб приложение для отслеживания годовой динамики прибыли от продаж 
по месяцам (**Диаграмма продаж по месяцам**), а так же визуализации структуру выручки 
в разрезе товарных категорий (**Диаграмма-Дерево**).  
## Installation

[ссылка на страницу](https://craftsoul001.github.io/various_tasks/SalesRevenue/index.html)

## Usage

Вводить можно либо значения категорий товаров, тогда **месячная сумма вычисляется
автоматом**. Либо значения по месяцам (списком либо отдельно на каждый месяц),
тогда значения категорий останутся по умолчанию и можно ввести потом. 


**Ввод значений дохода по месяцам (Динамика ежемесячных продаж)**  
- Передать значения, для каждого месяца, можно списком из 12 чисел через запятую в 
поле "Изменить значения". Чтобы применить список, нажмите кнопку (Применить список).  
- Можно выбрать месяц (поле "Выбранный месяц") и изменить ему значение вручную.  

**Ввод значений по категориям (Диаграмма-Дерево по проданным товарам за месяц)**  

- выбрать месяц в поле (Выбранный месяц)  
- Ввести значения для категорий товаров за определённый месяц (Диаграмма-Дерево) в поле
текстового ввода. Чтобы применить список, нажмите кнопку (Применить список).  
- Если сумма за месяц нулевая (по дефолту), то значения по категориям суммируются 
и добавляется везде (на график, и в список "Значения за 12 месяцев").  
- Если месячная сумма определена ранее, то суммарно значения по категориям не 
должны превышать значение месячной суммы, (введённые значения не применятся, возникнет ошибка).  
## Development
[Mermaid JS библиотека с открытым исходным кодом](https://mermaid.js.org/)(инструмент 
разработки для создания диаграмм)  
[mermaid.live](https://clck.ru/3VKUPs) - онлайн редактор  

Скрипты Mermaid для проекта:  
Динамика ежемесячных продаж (XY Диаграмма):

```text
xychart-beta
    title "Sales Revenue"
    x-axis [jan, feb, mar, apr, may, jun, jul, aug, sep, oct, nov, dec]
    y-axis "Revenue (in $)" 4000 --> 11000
    bar [5000, 6000, 7500, 8200, 9500, 10500, 11000, 10200, 9200, 8500, 7000, 6000]
```

Диаграмма-Дерево по проданным товарам:
```text
treemap-beta
"Monthly Revenue"
    "Кирпичи": 3000
    "Цемент": 1000
    "Лопаты": 500
```
